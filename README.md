
#  Library Management System

 📖 Overview
Library Management System is a web application developed using Python, Flask, HTML, CSS, JavaScript, and SQLite. It helps manage books, users, and library operations efficiently.A Library Management System built with PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap for managing books, users, issue/return operations, and admin functionalities.

##  Features
- Admin Login
- User Login
- Add Books
- Update Books
- Delete Books
- Search Books
- Issue Books
- Return Books
- Book Availability
- Dashboard

##  Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository
2. Install requirements
3. Run:

```bash
python app.py
```
